# AI 使用声明

由于本人并非JS高手，**只有C#基础**（这是我第一次写油猴脚本），所以合理使用**Copilot**量子速读了整个**6000+行代码**并生成了控制台调试代码和**最初的**油猴脚本，经测试有效后由**Deepseek**辅助我审查。  
我**逐行理解**了代码，并**亲自进行了调试和修改**，之后亲自进行了功能的增添和重构。

-------------------------------------------------------------

**严肃提示： AI生成的原始代码中夹带了不少无用代码，还有错误的、遗漏的逻辑，不能完全信任。虽然 Copilot 已经算是不错的了，但(我认为)人工审查是不能免除的，正如 [Copilot 官方文档](https://docs.github.com/en/enterprise-cloud@latest/copilot/get-started/best-practices#understand-copilots-strengths-and-weaknesses) 中描述的：**

> **Copilot 的设计目的并非：**  
>
> - 回答与编码和技术无关的提示。
> - 取代您的专业知识和技能。记住，您才是掌控者，而 Copilot 是您得力的助手。

-------------------------------------------------------------

### 我通过重构代码得到的经验教训

我在重构代码时使用了AI辅助分析，结果发现，AI确实只是**辅助工具**罢了，一定不能**完全**被AI牵着鼻子走！要有自己的想法，否则你写出来的多半是“屎山”

**要记住：代码是不会自己变干净的，它只会随着AI每一次胡乱地修改变得更脏、更劣化**
